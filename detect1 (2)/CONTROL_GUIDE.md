# K230 小球居中平衡 + PB21 单次往返

## 正常功能：小球居中平衡

上电后，只要 K230 持续发送有效的数据帧：

```text
$BALL,x,y,score\r\n
```

程序会以 `x = 320` 为中心目标，使小球维持在图像中心附近。控制器与速度、死区、PID、CAN 电机参数均沿用了 `newdetect.zip` 里的参数，未对这些平衡参数重新调节。

若 K230 报告：

```text
$BALL,-1,-1,0\r\n
```

或有效视觉数据中断超过 250 ms，电机将平滑停下。若此时正在执行 PB21 往返，往返会安全取消；重新收到有效数据后恢复普通居中平衡，而不会从丢球前的阶段继续运行。

## PB21 附加功能：单次往返

按下 TI 板 `PB21` 一次，会启动一次完整轨迹：

```text
中心 -> +5 cm -> -5 cm -> 中心
```

- 轨迹只会启动一次；运行中重复按 PB21 不会打断当前往返。
- 往返过程中仍由 K230 的小球位置作为反馈，并使用同一套闭环控制，不是按时间盲转。
- 每次到达换向点会先请求平滑停车，再在 CAN 停止指令已排队且等待短暂稳定时间后反向；这是为了避免旧方向命令与反向命令在总线繁忙时交错。
- K230 明确报“无球”、置信度不足或有效视觉数据中断超过 250 ms 时，会取消未完成的往返，防止恢复画面后按陈旧状态继续运动。
- 返回中心且小球速度足够低后，自动退出往返，恢复普通“中心平衡”模式。
- LED (`PA2`)：普通居中平衡时熄灭；单次往返运行时点亮。

轨迹的换向阈值沿用之前参考控制中使用的视觉位置阈值：达到约 `+3.50 cm` 后转向 `-5 cm`，达到约 `-3.50 cm` 后返回中心。目标本身仍分别是 `+5 cm` 与 `-5 cm`，这样可以在无编码器条件下减轻越界后的机械冲击。

## 引脚配置

- K230：`UART1`，`PA9 = RX`，`PA8 = TX`，115200 baud
- CAN：`CANFD0`，`PA13 = CAN_RX`，`PA12 = CAN_TX`
- 按键：`PB21`，低有效
- LED：`PA2`

## 方向确认

当前定义为：球在左侧时抬高水管，球在右侧时降低水管。若实物方向相反，只交换 `empty.c` 中：

```c
#define ZDT_DIRECTION_RIGHT_RAISE  (0x01U)
#define ZDT_DIRECTION_LEFT_LOWER   (0x00U)
```

对应的方向含义，或将这两个宏的值互换；不要先改 PID 正负号。
