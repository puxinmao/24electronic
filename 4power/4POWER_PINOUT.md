# 4power 引脚与接线

本文档对应当前 `empty.syscfg` 和电机软件映射。所有信号电平均为 3.3V。

## 车轮与通道

```text
                     车头
        +---------------------------+
        | C 左前             B 右前 |
        |                           |
        | D 左后             A 右后 |
        +---------------------------+
                     车尾
```

| 通道 | 实体车轮 | 所属侧 |
| --- | --- | --- |
| A | 右后 | 右侧 |
| B | 右前 | 右侧 |
| C | 左前 | 左侧 |
| D | 左后 | 左侧 |

`Motor_SetFour(a, b, c, d)` 的参数始终按物理通道 A/B/C/D 排列。
`Motor_SetLeft()` 控制 C/D，`Motor_SetRight()` 控制 A/B。

## 电机驱动

使用四路 TB6612FNG 驱动。电机本体只能接对应通道的驱动输出端，不要直接接 MCU GPIO、3.3V、5V 或 12V 电源。

| 通道/车轮 | 方向输入 | PWM 输出 | 编码器 |
| --- | --- | --- | --- |
| A / 右后 | `PB20 -> AIN1`，`PB13 -> AIN2` | `PB4 -> PWMA` | `PA24 <- A相`，`PA17 <- B相` |
| B / 右前 | `PB19 -> BIN1`，`PB18 -> BIN2` | `PB1 -> PWMB` | `PA16 <- A相`，`PA15 <- B相` |
| C / 左前 | `PA25 -> CIN1`，`PA22 -> CIN2` | `PA28 -> PWMC` | `PA26 <- A相`，`PB24 <- B相` |
| D / 左后 | `PA12 -> DIN1`，`PA13 -> DIN2` | `PA31 -> PWMD` | `PB9 <- A相`，`PA27 <- B相` |

| 信号 | MCU 引脚 | 接法 |
| --- | --- | --- |
| `STBY` | `PB0` | 连接所有 TB6612 模块的 `STBY` 并联端 |
| `VM` | 无 MCU GPIO | 接电机电源正极，例如 12V 电池正极 |
| `VCC` | MCU 3.3V | 接 TB6612 逻辑电源，不能接 12V |
| `GND` | MCU GND | 与电池负极、TB6612、编码器和所有传感器共地 |

PWM 使用 TIMA1 的 CCP0/CCP1 和 TIMG7 的 CCP0/CCP1，周期为 2000，频率约 16 kHz。A/B 共享 TIMA1，C/D 共享 TIMG7；四轮占空比可以独立设置，但同一组内频率相同。

## 编码器

每个编码器使用 A/B 两相信号，软件配置为输入、内部上拉、双边沿中断。

- 编码器 `VCC` 接 MCU 3.3V。
- 编码器 `GND` 接公共 GND。
- 若编码器模块输出 5V，必须先做电平转换，不能直接接 PA/PB 引脚。
- 编码器 A/B 相对调只会改变计数方向，不会损坏器件。

## 其他外设

| 功能 | 引脚与接线 |
| --- | --- |
| KEY1 | `PB8`，按键另一端接 GND |
| KEY2 | `PB15`，按键另一端接 GND |
| KEY3 | `PA7`，按键另一端接 GND |
| KEY4 | `PA14`，按键另一端接 GND |
| OLED I2C | `PB3 -> SDA`，`PB2 -> SCL`，另接 3.3V 和 GND |
| 调试串口 | `PA10 (TX) -> USB-TTL RX`，`PA11 (RX) <- USB-TTL TX`，115200，3.3V 电平 |
| 陀螺仪串口（仅接收） | `PB16 (UART2 RX) <- 陀螺仪 TX`，115200；陀螺仪 `RX` 不连接 |
| 预留 UART1 | `PA9 (RX)`、`PA8 (TX)`；不用于当前陀螺仪 |
| 灰度模块 | `PB12 <- OUT`，`PB17 -> AD0`，`PB7 -> AD1`，`PB6 -> AD2` |

## 供电与安全检查

```text
12V 电池正极 -> 保险丝 -> TB6612 VM
12V 电池正极 -> 降压模块 -> 开发板标注的 5V/VIN 输入
电池负极 -> 公共 GND
开发板 3.3V -> TB6612 VCC、编码器和低压传感器
```

1. 不要把 12V 接到 TB6612 的 `VCC`、MCU `3.3V`、任一 PA/PB GPIO、编码器、OLED 或 USB-TTL。
2. 不要把电机输出端接到 `VM`、GND、另一个驱动输出端或 MCU GPIO。
3. 电池正负极短接最先危及电池、导线、保险丝和驱动模块；接线前断开电池，用万用表确认 `VM` 与 GND 没有近似短路。
4. 电机正负线对调只会改变转向；编码器 A/B 对调只会改变计数方向。
5. 首次四轮测试应架空车轮。若驱动板、电源线或电池明显发热，立即断开电机电源。
