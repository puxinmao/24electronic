## 一、电机驱动 (TB6612FNG)

| 信号 | 引脚 | 方向 | 功能说明 |
|:----|:----:|:----:|:---------|
| AIN_1 | PA16 | 输出 | 左电机方向 1 (H=正转, L=反转) |
| AIN_2 | PA17 | 输出 | 左电机方向 2 |
| BIN_1 | PA24 | 输出 | 右电机方向 1 |
| BIN_2 | PA25 | 输出 | 右电机方向 2 |
| STBY | PB9 | 输出 | 待机控制 (H=使能, L=待机) |

**控制逻辑：**

| 状态 | AIN_1 | AIN_2 | BIN_1 | BIN_2 |
|:----|:----:|:----:|:----:|:----:|
| 正转 | H | L | H | L |
| 反转 | L | H | L | H |
| 刹车 | H | H | H | H |
| 滑行 | L | L | L | L |

**驱动文件：** `motor.h` / `motor.c`

## 二、电机 PWM (TIMA1)

| 信号 | 引脚 | 功能 | 说明 |
|:----|:----:|:----|:-----|
| CCP0 | PB4 | TIMA1_CCP0 | **左电机** PWM (周期 2000) |
| CCP1 | PB1 | TIMA1_CCP1 | **右电机** PWM (周期 2000) |

- 定时器时钟: 32MHz, 不分频
- PWM 频率: 32MHz / 2000 = **16kHz**
- 占空比范围: 0 ~ 2000

**驱动文件：** `motor.h` / `motor.c`

---

## 三、编码器 (霍尔传感器 ×2)

| 信号 | 引脚 | 方向 | 功能 |
|:----|:----:|:----:|:-----|
| LA (左 A 相) | PB7 | 输入 + 上拉 | 左编码器 A 相 (双边沿中断) |
| LB (左 B 相) | PB6 | 输入 + 上拉 | 左编码器 B 相 (双边沿中断) |
| RA (右 A 相) | PB0 | 输入 + 上拉 | 右编码器 A 相 (双边沿中断) |
| RB (右 B 相) | PB16 | 输入 + 上拉 | 右编码器 B 相 (双边沿中断) |

- 中断向量: `GROUP1_IRQHandler` (GPIOB)
- 解码方式: **AB 相 4x 查表法**
- 触发方式: 双边沿 (上升沿 + 下降沿)
- 查表: 每步 +1(正转) / -1(反转) / 0(非法)

**驱动文件：** `encoder.h` / `encoder.c`

## 五、JY901S 陀螺仪 (UART1)

| 信号 | 引脚 | 方向 | 说明 |
|:----|:----:|:----:|:-----|
| TX ← | PA9 | 输入 (RX) | JY901S → MCU (仅接收) |

- 硬件外设: **UART1**
- 波特率: **115200**
- 数据位: 8, 停止位: 1, 无校验
- 接收方式: **FIFO + RX/RX_TIMEOUT 中断**
- 协议: 11 字节帧, 帧头 0x55
  - 0x51 → 加速度 + 温度
  - 0x52 → 角速度
  - 0x53 → 姿态角 (Pitch/Roll/Yaw) + 版本
- 输出频率: ~100Hz (默认)

**驱动文件：** `wit.h` / `wit.c`

> 注意: JY901S 的 **TX** 接 MCU 的 **PA9** (RX), 两者 TX⇔RX 交叉。

## 六、调试串口 (UART0)

| 信号 | 引脚 | 方向 | 说明 |
|:----|:----:|:----:|:-----|
| TX | PA10 | 输出 | MCU → 串口助手 |
| RX | PA11 | 输入 | 串口助手 → MCU (备用) |

- 硬件外设: **UART0**
- 波特率: **115200-8N1**
- 功能: 调试输出 (编码器计数 / YPR 数据 / 状态信息)
- 支持命令: 运行中自动打印 `Y,E,C` 等数据

**驱动文件：** `uart_debug.h` / `uart_debug.c`

## 八、按键 ×4

| 信号 | 引脚 | 方向 | 功能 |
|:----|:----:|:----:|:-----|
| KEY1 | PB13 | 输入 + 上拉 | **启动** — 锁定偏航角, 直行 |
| KEY2 | PA15 | 输入 + 上拉 | **停止** — 刹车 + 待机 |
| KEY3 | PB18 | 输入 + 上拉 | *(未使用)* |
| KEY4 | PB19 | 输入 + 上拉 | *(未使用)* |

- 按下 = 低电平 (内部上拉)
- 软件消抖: 50ms
- KEY1/KEY2 功能实现在 `empty.c` 主循环
