# 小球居中控制方案

## 控制结构

K230 发送 `$BALL,x,y,score`，其中 `x=0..639`。协议层先得到
`cx=x-320`，控制层采用分段线性映射：

- `cx=-320 -> -1250`（-12.50 cm）
- `cx=0 -> 0`
- `cx=319 -> +1250`（+12.50 cm）

控制器采用可由视觉数据真正闭环的标准级联结构：

1. 球位置外环 PID：中心位置误差输出期望球速度。
2. 球速度内环 PID：由相邻视觉帧估算并滤波球速度，输出电机脉冲率。
3. 速度环输出按短脉冲时间执行经验证的 Emm_V5 `F6` 连续速度命令。
4. 电机驱动器内部完成电流和速度闭环。

把位置放在速度内环、速度放在位置外环会形成不合理的环路依赖；工程中采用的是伺服系统常用的“位置外环、速度内环”。

## 方向与安全

- 球在左侧（负值）：右转电机，上移水管。
- 球在右侧（正值）：左转电机，下移水管。
- 进入 ±0.20 cm 且球速足够小时停止；超过 ±0.35 cm 才重新动作，防止中心抖动。
- K230 明确报告无球或 250 ms 没有有效帧时，立即发送 `FE` 停止命令。
- 初始上机必须悬空或解除负载低速验证方向。若电机观察方向相反，只交换 `control_config.h` 中两个方向宏。

## 硬件与协议

- K230：`UART_2`，PA8/PA9，115200 baud。
- 张大头 CAN 收发器：MCAN0，PA12=CAN TX、PA13=CAN RX。
- 电机设置：Emm_V5、`P_Serial=CAN1_MAP`、`ID_Addr=1`、`Checksum=0x6B`。
- 当前使用已由参考工程验证的 `F6` 速度帧：方向、速度、加速度档位、同步标志和校验字节。

## 首次通信自检

将 `APP/control_config.h` 内的 `ZDT_STARTUP_TEST_ENABLED` 改为 `1U` 后重新编译烧录。上电后电机应右转 300 ms、停止 300 ms、左转 300 ms；测试结束后恢复为 `0U`。该测试不依赖 K230，能直接区分视觉数据问题与 CAN/电机问题。

调试器同时观察：`g_zdt_can_tx_success_count` 增长代表该帧已获得 CAN ACK；`g_zdt_can_tx_failure_count` 增长代表 PA12/PA13 至电机的 CAN 物理链路没有成功发送。

## 调参顺序

1. 先把 `POSITION_PID_KI`、`VELOCITY_PID_KI` 和两个 `KD` 暂设为 0，只调两个 `KP`。
2. 从较小的 `VELOCITY_PID_KP` 开始，让电机动作柔和且方向正确。
3. 增加 `POSITION_PID_KP`，直到小球能回中但尚未持续振荡。
4. 增加位置环 `KD` 抑制越过中心，再用很小的 `KI` 消除机构摩擦造成的静差。
5. 最后按需提高 `ZDT_MOTOR_SPEED_RPM`、`ZDT_MOTOR_ACCEL_LEVEL` 和脉冲率上限。

所有初始参数集中在 `APP/control_config.h`，当前值偏保守，必须根据丝杆导程、细分、负载和 K230 帧率实机整定。
